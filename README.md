# Avito Analytics via GitHub Actions

Автоматический ежедневный отчёт по объявлениям Авито.
Крутится на серверах GitHub (бесплатно), результат выгружается на Beget через FTP.

## Как это работает

1. Каждый день в **23:00 по Новосибирску** (16:00 UTC) GitHub Actions запускает скрипт
2. Скрипт подключается к Avito API и собирает статистику за 90 дней
3. Генерирует HTML-отчёт с 9 колонками
4. Загружает его на Beget через FTP в `public_html/avito/`
5. Открываете отчёт по `https://ikeda.ru/avito/latest.html`

## Что в отчёте

**Колонки:**
- № — порядковый номер
- Название — короткое имя (сокращено по словарю: «Плитка», «Крошка», «Газон» и т.д.)
- Город — только название города, без региона и улицы
- Сегодня — просмотры за сегодня + дельта к вчера
- За 90 дней — сумма просмотров за 90 дней
- Контакты — контактов за 90 дней
- Избранное — добавлений в избранное за 90 дней
- Дней на Авито — сколько дней крутится объявление
- Лимит контактов — лимит из API (если доступен)

**Функции:**
- Поиск по названию и городу (ищет и в коротких, и в полных заголовках)
- Сортировка по любой колонке
- Ссылки на объявления при клике на название

## Файлы данных

- `history.json` — история ежедневных просмотров за 90 дней
- `items_cache.json` — кеш с датами публикации (чтобы не дёргать API повторно)
- `data/external_context.sqlite` — погодный и календарный контекст для анализа внешних факторов

Эти файлы автоматически сохраняются между запусками через GitHub Actions Cache.

## Внешний контекст: погода и календарь

Проект автоматически сохраняет внешний контекст для будущего анализа зависимости метрик Авито от погоды и календаря.

Что собирается:

- погода по городам объявлений через бесплатный Open-Meteo Historical Weather API;
- календарный контекст России за 2026 год: выходные, праздники, длинные выходные, предпраздничные дни, межпраздничные периоды;
- данные сохраняются в SQLite-таблицы `weather_daily`, `calendar_daily` и `avito_daily_enriched`;
- повторный запуск не дублирует данные: погода кешируется по ключу `date + city`, календарь по ключу `date`.

Конфиги:

- `config/cities.json` — координаты и timezone городов;
- `config/ru_calendar_2026.json` — производственный календарь и поведенческие периоды.

Ручной пример запуска:

```bash
python external_context.py --date 2026-05-07 --cities Новосибирск Красноярск Омск
```

Принудительно обновить погоду, игнорируя кеш:

```bash
python external_context.py --date 2026-05-07 --force-update
```

В ежедневном `avito_report.py` внешний контекст обновляется после сбора Avito-данных. Если Open-Meteo недоступен или город отсутствует в конфиге, это пишется в лог, но основной HTML-отчет продолжает формироваться.

После обновления внешнего контекста скрипт также сохраняет строки объявлений в таблицу `avito_daily_enriched`. Это отдельная накопительная таблица для будущей аналитики: одна строка = одно объявление за одну дату с Avito-метриками, погодой и календарными признаками. Ключ строки: `date + account + ad_id`, поэтому повторный запуск за тот же день обновляет запись, а не создает дубль.

Функции для будущей аналитики:

- `build_external_context_for_report(report_date, cities)` — загрузить и сохранить погоду/календарь;
- `enrich_avito_rows_with_weather_and_calendar(rows, report_date)` — добавить погодные и календарные поля к строкам Avito-отчета.
- `save_enriched_avito_rows(rows, report_date)` — сохранить обогащенные строки в `avito_daily_enriched`.

## Настройка с нуля

Если настраиваете впервые — все шаги описаны подробно в предыдущей версии README. Ключевое:

1. Получить API-ключи в Avito: https://www.avito.ru/professionals/api/
2. Создать репозиторий на GitHub
3. Загрузить файлы этого проекта
4. Добавить 7 секретов в Settings → Secrets:
   - `AVITO_CLIENT_ID`, `AVITO_CLIENT_SECRET`, `AVITO_USER_ID`
   - `FTP_HOST`, `FTP_USER`, `FTP_PASSWORD`, `FTP_REMOTE_DIR`
5. Создать папку `/avito/` на Beget через FileZilla
6. Нажать кнопку **Run workflow**

## Защита отчёта паролем

Отчёт защищён через `.htaccess` + `.htpasswd` в папке `/avito/` на Beget.
Чтобы сменить пароль — используйте htpasswd-генератор и обновите `.htpasswd`.

## Техническое

- Python 3.11
- Зависимости: `requests`
- Запуск через `cron: '0 16 * * *'` в workflow
- Кнопка ручного запуска через `workflow_dispatch`
- FTP-выгрузка через `SamKirkland/FTP-Deploy-Action@v4.3.5`
